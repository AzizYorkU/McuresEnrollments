          Source: Ontario university headcounts, 2012-13 to 2024-25, one file per breakdown. With no filter, figures, growth, ranks and the institution table use the domestic/international file; with a field of study, gender, citizenship, credential or year of study picked they use that file, whose totals can run slightly lower. Peers combined adds up every member of the chosen group; ranks count York and the group’s members (1 = highest). Large universities are those with more than 20,000 students in 2024-25; the groups are listed in data/peer_groups.csv. Breakdown shares use each file’s own total, which can run up to about 2% lower where a group isn’t reported.

          Data: Ontario university headcounts by institution, 2012-13 to 2024-25. Source code and data: github.com/AzizYorkU/McuresEnrollments.
